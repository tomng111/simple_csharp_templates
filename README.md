# Distance Measure Using HCSR04 and C#
Arduino MEGA 2560 - HCSR04<br />
## Essential Commands<br />
### Operating
- Select the COM-PORTS and BAUDRATE<br />
- Click the CONNECT button<br />
- Control the LED1 and LED2 using the pairs 1-EIN/1-AUS and 2-EIN/2-AUS or the following commands e1/a1 and e2/a2<br />
- DISTANZ - The distance value detected using HCSR04
